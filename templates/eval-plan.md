## 2. 样本集

## 3. 错误分析（每轮迭代前做）

1. 亲自读 20–50 条模型输出，逐条写下自由笔记：哪里不对、为什么。
2. 把笔记归类成失败类型，并统计每类出现的次数。
3. 先修出现次数最多的那一类。

| | | | | |

## 4. 判定方式

- 用**通过 / 不通过**二元判断，不用 1–5 分。
- 能用代码检查的（格式、必含字段、长度、引用是否存在）优先用代码断言。
- 需要“大模型当裁判”的，每种失败类型单独写一个判定提示，并用人工标注校准：判定结果和人工标注的一致率要达到可接受水平。
